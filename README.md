# Socrenchus Landing Page

A modern, single-page landing page for Socrenchus - the first Socratic AI that uses SPAR (Socratic Sparring) to turn your internal monologue into Intellectual Equity.

## 🚀 Features

- **Modern Tech Stack**: Built with React 18, Vite, and Tailwind CSS
- **Dark Mode Design**: Futuristic "Code & Cosmos" aesthetic with Slate-950 background
- **Cyber-Blue & Violet Gradients**: Eye-catching accent colors
- **Responsive Layout**: Mobile-first design that works on all devices
- **Glassmorphism Effects**: Beautiful backdrop blur on feature cards
- **Micro-animations**: Smooth hover effects and transitions
- **Accessible**: Proper ARIA labels and semantic HTML
- **Toast Notifications**: User-friendly feedback system

## 🛠️ Tech Stack

- **Framework**: React 18 (functional components with hooks)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Fonts**: Inter (Google Fonts)
- **Deployment**: GitHub Pages via GitHub Actions

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the `main` branch. The deployment workflow is configured in `.github/workflows/deploy.yml`.

## 📄 Sections

1. **Navigation**: Transparent header with Socrenchus logo and "Join Beta" CTA
2. **Hero**: Bold headline with email capture form
3. **Stable Marriage Feature**: Explains the Gale-Shapley algorithm for idea matching
4. **Midwife Workflow**: Three-step process (Spar, Synthesize, Publish)
5. **Footer**: Social links and copyright information

## 🎨 Design Principles

- High-signal, direct language (no AI clichés)
- Bold, oversized typography
- Minimalist, high-contrast components
- Subtle animations for engagement
- Mobile-first responsive design
